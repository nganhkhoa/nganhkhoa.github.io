# My website

## Prepare, run, build

Requires npm and lamdera.

```
curl https://static.lamdera.com/bin/lamdera-1.3.2-linux-x86_64 -o /usr/local/bin/lamdera
chmod a+x /usr/local/bin/lamdera
```

```
npm install
npm start
```
